# CodeArena

Веб-платформа для решения алгоритмических задач и участия в соревнованиях. Пользователь регистрируется, открывает задачу, пишет код в редакторе и получает вердикт. Организатор создаёт турнир, участники регистрируются, а таблица результатов считается по успешным отправкам.

## Что нужно установить

- Python 3.9 или новее. На Windows, если команда `python` не находится, используйте `py -3`.
- Node.js 20 или новее и npm: https://nodejs.org

Проверка кода работает в двух режимах:

- **Демонстрационный режим** включается сам, если Judge0 не настроен. Код выполняется локально по тестам из базы. В интерфейсе и в ответе API это явно подписано как «Демонстрационный режим». Python доступен всегда, потому что используется тот же интерпретатор, что и у backend. C++, Java и JavaScript проверяются, только если в PATH есть `g++`, `javac`/`java` или `node`.
- **Judge0** используется, когда в `backend/.env` указан адрес сервера. Тогда вердикты приходят от Judge0.

## Запуск

Откройте два терминала из корня проекта.

### Backend

```powershell
cd backend
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Если `py` нет, замените первую команду на `python -m venv .venv`. На macOS и Linux активация другая: `source .venv/bin/activate`.

При первом запуске создаётся файл `backend/codearena.db` и в него записываются 9 задач с открытыми примерами и скрытыми тестами. Пароли хранятся как PBKDF2-хеш, не в открытом виде.

API доступен на http://127.0.0.1:8000 , описание маршрутов — на http://127.0.0.1:8000/docs .

### Frontend

```powershell
cd frontend
npm install
npm run dev
```

Сайт откроется на http://127.0.0.1:5173 . Запросы к `/api` проксируются на backend, поэтому оба процесса должны быть запущены.

## Как пользоваться

1. Зарегистрируйтесь. Роль выбирается при регистрации:
   - **Участник** решает задачи и записывается на турниры.
   - **Организатор** дополнительно создаёт, редактирует и публикует соревнования.
2. На главной после входа видны число решённых задач, ближайшие турниры и последние отправки.
3. В каталоге задач есть поиск и фильтр по сложности. Зелёная точка означает, что вы уже получили OK.
4. На странице задачи слева условие, справа Monaco Editor. «Запустить» проверяет только примеры и ничего не сохраняет. «Отправить решение» гоняет все тесты и пишет результат в историю.
5. Вердикты: OK, WA, TLE, RE, CE.
6. Организатор открывает «Создать соревнование», выбирает задачи, дату и длительность. Черновик виден только ему. После публикации турнир видят все.
7. Участник регистрируется, открывает задачи турнира и отправляет решения оттуда. В таблицу попадают только такие отправки, сделанные в интервале турнира.
8. Место считается так: больше решённых задач — выше. При равенстве выше тот, у кого меньше суммарное время от старта турнира до первого OK по каждой задаче.

Пока турнир не начался, регистрацию можно отменить. После старта состав фиксируется, а условие уже нельзя менять.

## Judge0

Скопируйте `backend/.env.example` в `backend/.env`.

Свой сервер Judge0:

```env
JUDGE0_URL=http://127.0.0.1:2358
```

RapidAPI Judge0 CE:

```env
JUDGE0_URL=https://judge0-ce.p.rapidapi.com
JUDGE0_API_KEY=ваш_ключ
JUDGE0_API_HOST=judge0-ce.p.rapidapi.com
```

Идентификаторы языков по умолчанию соответствуют Judge0 CE: Python 71, C++ 54, Java 62, JavaScript 63. Если у вашего сервера другие id, задайте `JUDGE0_LANG_PYTHON`, `JUDGE0_LANG_CPP`, `JUDGE0_LANG_JAVA`, `JUDGE0_LANG_JAVASCRIPT`.

Перезапустите backend. В шапке сайта вместо демонстрационного предупреждения появится строка про Judge0.

Поменяйте `SECRET_KEY` в `.env`, если сайтом пользуется кто-то кроме вас.

## Проверка backend

Из папки `backend`, с активированным виртуальным окружением:

```powershell
python smoke_test.py
```

Скрипт поднимает временную базу, прогоняет регистрацию, все эталонные решения, вердикты WA, CE и TLE, создание турнира и таблицу результатов.

## Структура

```text
backend/app/main.py            точка входа FastAPI
backend/app/models.py          таблицы Users, Problems, TestCases, Contests,
                               ContestProblems, Registrations, Submissions
backend/app/routers/           регистрация, задачи, отправки, турниры
backend/app/judge.py           Judge0 и демонстрационная проверка
backend/app/seed.py            стартовые задачи
frontend/src/pages/            страницы интерфейса
frontend/src/components/       общая шапка, кнопки, бейджи
```

Демонстрательный режим запускает присланный код на вашей машине. Он предназначен для локальной разработки, а не для публичного сервера. Для общей установки используйте Judge0.
